## Run Locally

This project has been scaffolded, but dependencies are not installed yet.

### 1. Install Node.js

Install the LTS version from:

`https://nodejs.org/`

After installation, verify in Terminal:

```bash
node -v
npm -v
```

### 2. Install dependencies

Open Terminal and run:

```bash
cd ~/Desktop/yixin-portfolio
npm install
```

### 3. Start the website

```bash
npm run dev
```

Then open:

`http://localhost:3000`
